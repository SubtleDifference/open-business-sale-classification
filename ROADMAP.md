# Towards v1.0

The current release is a draft open source classification initiative, version `0.5.0-draft.1`.

1. Resolve the [focused definition and overlap questions](docs/review-notes.md) with stakeholder input, applying the [category-necessity and buyer-discovery criteria](CONTRIBUTING.md#category-proposals).
2. Check that the interoperability documentation explains sender-to-receiver agreements on format, catalogue version, classification behaviour and optional characteristics. Individual integrations remain implementation-specific; see the [interoperability guide](docs/integration.md).
3. Agree the v1.0 scope, catalogue version and editorial status decisions. A proposed entry is not automatically unsuitable for a stable release.

This roadmap does not imply formal industry recognition or provider adoption.
